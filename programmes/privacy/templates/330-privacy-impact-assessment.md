# Privacy Impact Assessment

> [!NOTE]
> **Screen first.** If the answer to all five questions below is no, record that
> and stop — the assessment is complete and took ten minutes. A process that
> demands the full document every time is one that gets skipped when it matters.

## Screening

| | Yes / No |
|---|---|
| Does it involve personal information we do not already hold? |  |
| Does it use information we hold for a new purpose? |  |
| Does it involve a new system, supplier or integration? |  |
| Will information be stored or accessed outside Canada? |  |
| Will a decision about a person be made or significantly informed by automated processing? |  |

*Any yes — continue. All no — record and close.*

## Rights

- How will an access request be answered for this data?
- How will a correction be applied, including to copies?
- How will withdrawal of consent be given effect?
- How long will it be kept, and under which retention class?

## Automated decisions

*If a decision about a person is made or significantly informed by automated
processing: what the decision is, what information it uses, how a person can ask
for the reasons, and how they can ask for it to be reviewed by a human. In
Quebec this disclosure is required; everywhere else it is the disclosure people
most often complain about not having had.*
