# Privacy Request Response

> [!IMPORTANT]
> **The thirty days run from the day the request reached the organisation**, not
> from the day it reached the privacy officer. Fill in *Received on* with the
> earlier date even where that leaves fewer days — an incorrect start date is
> the most common reason a response is late and nobody notices.
