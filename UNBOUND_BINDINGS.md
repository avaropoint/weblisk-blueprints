# Unbound bindings

**69 bindings name something their target blueprint does not declare** — all
69 of them pattern behaviours, and no types or `behaviors:` entries. Measured
on wt/layering, 2026-11-05, by
[`checks/unbound-bindings.py`](checks/unbound-bindings.py); the tables below
are its `--markdown` output, and are regenerated by running it, never edited
by hand.

A binding is what generation reads to know a thing exists. An unbound one means the
model is asked to produce something with no definition, so it invents one — and
nothing about that is visible in the generated code afterwards.

What changed since the last measurement. This file recorded 86 — 80 types and
6 behaviours — as `weblisk validate` reported them. All 86 are gone: renamed,
authored, or removed with the binding. At main 2007b64 the script counted 73,
all pattern behaviours; wt/layering removed four (architecture/gateway now
binds the behaviours auth-session, auth-token and user-management declare, and
no longer binds architecture/admin).

Why `weblisk validate` did not see these. Its rule (weblisk-cli
`engine/dispatch/validate_corpus.go`, "a binding is not a wish") reads a
binding's `types:` and `behaviors:`, and reads them from a Dependencies
section only. Most framework blueprints bind a pattern's behaviour as
`patterns: - behavior:`, which it does not read, so every row below is
invisible to it and it reports none. The script reads all three forms, from
the Dependencies section and from a Declaration that nests the same
`requires` (architecture/orchestrator), and reads what a target declares as
the CLI does.

Split by whether the target declares something of the same kind with a
similar name. **Nothing here has been changed.** Binding a contract to the wrong
behaviour is worse than an honest fault, so each rename needs confirming by
somebody who knows what was meant. The 33 `startup-sequence`,
`shutdown-sequence` and `health-reporting` rows are one question:
architecture/agent describes its lifecycle in prose and declares no contract
for an agent to bind.
