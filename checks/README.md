# Checks

Small checks the corpus runs on itself, for rules no tool checks yet. Each one
reads its rules from the corpus file that states them and keeps no copy, and
each runs with a control: a case the check must fail, so that a check which
reaches nothing cannot pass.

```
checks/run.sh
```

runs them all and exits 0 only when every check passes and every control
fails. They need Python 3 and PyYAML, and OpenSSL 3.5 or later. A check that
cannot run fails; it never passes for want of something to read, and OpenSSL's
leg of the statement vectors is no exception. The one exception is the
statement vectors' circl and noble legs ([`ml-dsa/`](ml-dsa/)), and only for
want of the tool: with no `go` on PATH, or without the pinned
`@noble/post-quantum` (`npm ci --ignore-scripts` in `checks/ml-dsa`, or
`NOBLE_DIR` naming a directory that holds it), the leg prints `NOT RUN`, never
`ok`, and `REQUIRE_ALL_VERIFIERS=1` makes it a failure. A `go` that is on PATH
and cannot build the generator — a compile error, or a module cache without
circl — fails. [`version-bump.py`](version-bump.py) is NOT RUN on the same
terms where there is no base revision to compare against, as in a shallow or
new clone.
